feat: Implement RLHF with Experiential Self-Critique

This commit introduces a major enhancement to the AGI agent by implementing Reinforcement Learning from Human Feedback (RLHF) with an innovative "Experiential Self-Critique" mechanism.

Key changes include:
- **RLHF Framework:**
  - Added `trl` and `transformers` dependencies.
  - Implemented `RewardModel` (`src/rlhf/reward_model.py`) for learning human preferences.
  - Created `RLHFOracle` (`src/rlhf/oracle.py`) to guide agent's decision-making based on learned rewards.
  - Developed `collect_preferences.py` script for human feedback data collection.
  - Developed `train_reward_model.py` script to train the Reward Model.
  - Added `verify_data.py` for robust data validation.
- **Agent Enhancement:**
  - Modified `Agent` (`src/agent/agent.py`) to generate multiple candidate actions and use the `RLHFOracle` to select the best one.
  - Updated `PrometheusCognitiveCore` (`src/cognitive_core/prometheus_core.py`) to support temperature for diverse response generation.
- **Memory System Refinement:**
  - Upgraded `EpisodicMemory` to `VectorEpisodicMemory` (`src/agent/memory.py`) using LanceDB and Sentence-Transformers for semantic search.
  - Pinned core ML library versions in `pyproject.toml` for dependency stability.
- **Infrastructure & Documentation:**
  - Updated `main.py` to integrate all new components.
  - Documented the new RLHF system in `agi_project_collaboration.md`.
  - Marked RLHF as [COMPLETED] in `project_roadmap.md`.
  - Addressed various dependency, import path, and runtime issues (e.g., forcing CPU usage for models).

This feature significantly advances the agent towards autonomous learning and self-improvement, aligning with the "Chimera" project philosophy.
